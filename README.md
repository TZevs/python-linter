## Setup
### Installation
```terminal
git clone https://github.com/TZevs/python-linter.git
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
### Usage
```terminal
python linter.py <filepath>
```
> `<filepath>`: of the file you want the linter to check.
